These files are the Pokémon Essentials v18-format PBS files that came in with the
all-regions map pack (commit 2ebedbc2). The game runs on Essentials v21.1, whose
compiler can't read them, so they were converted (encounters, trainers,
trainer types) or replaced with the v21.1 data (abilities, items, moves,
pokemon, types, phone) and kept here only for reference. Files in subfolders
of PBS/ are ignored by the compiler.
